## What the record does not hold

- Mentori: the passage ids each sub-call was handed. The frozen record holds how many chunks each call was handed (`generation.calls[].n_passages`, used above for sub-calls with paper text) but not their ids, so its papers are those returned to the code, an upper bound. Passages handed to a sub-call as strings carry no id and are not counted as paper text.
- Mentori: which kind each gate rejection was is not recorded; the kinds above are inferred from the call order and are given only where every root placement agrees.
- Package: it has no gate, so no rejection count. A sub-call given only text the model wrote (a summary of earlier sub-calls) reads no paper by this measure, even when that text came from one. A copy shorter than 127 characters, or text shared with another paper, may be missed (sampled windows).
- Package in depth: 71 (answer, paper) pairs would reach 2,000 characters only by counting text sent to several sub-calls again (the earlier summed rule); they are not in depth here.
