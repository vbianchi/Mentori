## What it does

The method is the one README D213 (2) fixed before any run. G4 draw 1 (one run per index; 12 indexes: 5, 10, 20, 50 core papers by 0, 1, 3 distractors per core paper), answerable questions whose papers are all in the index, final-key judge rows. Pass is judge correctness 4 or more (primary) or 3 or more (secondary).

Model, as the submitted S11 (scripts/S11_corpus_mixed_model.R): logistic, random intercept per question, `pass ~ strategy * log2c + ratio + (1 | cluster)` (lme4 2.0.1, R 4.5.2), the distractor level read as a factor. One fit per strategy against single pass: RLM-10 primary; multi-hop, verified pass, RLM-5 and RLM-20 secondary and exploratory, unadjusted. The term reported is the strategy by log2(core papers) interaction: the change in log odds of passing against single pass per doubling of core papers.

Question sets: (a) the 22 asked at every size (primary), 528 rows per fit; (b) all in-scope questions, 86 questions, 1,428 rows per fit.

Interval: two-sided 95% percentile, 10,000 cluster-bootstrap resamples of questions, seed fixed; each resample refits the glmer (S11 refitted a plain glm). A refit that fails is dropped and counted ("refits ok"); D213 says nothing about failed refits. The Wald interval and P in results.md are labelled as outside D213's method.

Companion: RLM-10 minus single pass at 50 and at 20 core papers on the 86 questions, and the gap between the two, same bootstrap.
