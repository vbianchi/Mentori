# Figure 7, title and legend (draft)

Written by `scripts/S481_fig6_d138.py` from the plotted numbers. Data stamp: PROVISIONAL: 2,420 of 2,420 attempts, 11 of 11 variants complete, records of 2026-11-04 08:35 CET; after the S4 reruns (D75, D80 V1, D81).

**Figure 7 | Code-generation pass rates by prompting strategy, task difficulty and outcome.** An attempt is one model variant (a model at one thinking setting), one prompting strategy and one of 20 data-analysis operations on two datasets (airway RNA-seq and NCCTG lung survival), run once (165 attempts run again after a rule change, the later run counted); 2,420 attempts in all (11 variants × 11 strategies × 20 operations). An attempt passes when its code returns values matching the reference. **a**, Pass rate of each model variant (column) under each prompting strategy (row): each cell is the percentage of its 20 attempts, one per operation, that passed. Bold rows pool the strategies of each family (3 free-form, 4 introspection and 4 structured); bottom row, pooled structured minus pooled free-form (percentage points). Columns: Gemini, then open-weight, each ordered high to low by pooled free-form, then overall, pass rate. Gemini's lowest thinking setting is labelled low. **b**, Pass rate of each operation by prompting family (colour and marker) and difficulty, all 11 variants pooled: each dot is one operation, its pass rate over 33 free-form, 44 introspection or 44 structured attempts. Box, median and quartiles of the dots; whiskers, range; n = 6 simple, 8 medium and 6 complex operations per box. **c**, Outcome of the attempts of each prompting strategy (row), as percentages: each Gemini bar holds 80 attempts (4 variants on 20 operations) and each open-weight bar 140 (7 variants); the number on each bar is the percentage passed. Wrong values: the code returned values that did not match the reference. No result: the code returned no values. Tool or call failure, other: a tool or model call failed, the reply filled its context or output cap, the harness or a step failed, no code or another failure.
