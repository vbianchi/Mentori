**Figure 7 | Code-generation pass rates by prompting strategy, task difficulty and outcome.** An attempt is one model variant (a model at one thinking setting), one prompting strategy and one of 20 data-analysis operations on two datasets (airway RNA-seq and NCCTG lung survival), run once (165 attempts run again after a rule change, the later run counted); n = 2,420 attempts (11 variants × 11 strategies × 20 operations). An attempt passes when its code returns values matching the reference. **a**, Pass rate per model variant (column) and strategy (row), n = 20 attempts per cell. Bold rows pool each family (n = 60 free-form, 80 introspection and 80 structured attempts per variant); bottom row, pooled structured minus free-form (percentage points). Columns: Gemini, then open-weight, each ordered high to low by pooled free-form, then overall, pass rate. Gemini's lowest thinking setting is labelled low. **b**, Pass rate of each operation by family and difficulty, all 11 variants pooled; one dot per operation (33 free-form, 44 introspection or 44 structured attempts). Box, median and quartiles; whiskers, range; n = 6 simple, 8 medium and 6 complex operations. **c**, Outcome of each attempt per strategy: Gemini, n = 80 attempts per bar (4 variants on 20 operations); open-weight, n = 140 (7 variants); the number is the percentage passed. Wrong values: the code returned values that did not match the reference. No result: the code returned no values. Tool or call failure, other: a tool or model call failed, the reply filled its context or output cap, the harness or a step failed, no code or another failure.
