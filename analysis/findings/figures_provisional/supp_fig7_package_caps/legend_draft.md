**Supplementary Figure 7 | Outcome and turns of Zhang RLM on the depth-sweep questions, across turn caps.** Each answer is one of 86 depth-sweep questions answered by gemini-3-flash in Zhang RLM, the RLM package released by the method's authors (rlms 0.1.3; ref. 27), in which the model writes and runs code over the 20-paper corpus for up to a set number of turns, the turn cap. Each question was answered three times at each cap (1, 2, 3, 5, 7, 10, 15, 20, 30 and 50). **a**, How each answer ended: one bar per turn cap (vertical axis), divided by the share (%) of that cap's answers (horizontal axis) that ended each way, each way a colour named in the key: an answer within the cap; an answer from the closing call the package makes when the cap is reached; a closing call that returned code, kept as the answer; an answer with no text; a failed model call in a turn; or the package's own code failed, a TypeError raised inside it (2 answers: cap 15, 1; cap 20, 1). **b**, Turns used per answer (horizontal axis, caps evenly spaced) at each turn cap (vertical axis), for the answers that did not fail; the closing call is not counted. Each grey dot is one answer, boxes span the first to the third quartile, the line is the median and whiskers reach the smallest and largest value; n = 258, 258, 257, 257, 256, 256, 254, 256, 256 and 254 answers from cap 1 to cap 50.
