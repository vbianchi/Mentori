# Supplementary Figure 14, title and legend (draft)

Written by `scripts/S481_fig6_d138.py` from the plotted numbers. Data stamp: PROVISIONAL: 2,420 of 2,420 attempts, 11 of 11 variants complete, records of 2026-11-04 08:35 CET; after the S4 reruns (D75, D80 V1, D81).

**Supplementary Figure 14 | How code-generation attempts failed, per model variant.** An attempt is one model variant (a model at one thinking setting), one prompting strategy and one of 20 data-analysis operations on two datasets (airway RNA-seq and NCCTG lung survival), run once (165 attempts run again after a rule change, the later run counted); 2,420 attempts in all (11 variants × 11 strategies × 20 operations). An attempt passes when its code returns values matching the reference. Each bar is the share of one model variant's attempts (row) that failed under one prompting family (column: free-form, 3 strategies; introspection, 4; structured, 4), one attempt per strategy and operation; x axis, attempts failed as a percentage of that variant's attempts in that family. The bar is split by kind of failure (colour and pattern, key above). Wrong values: the code returned values that did not match the reference. No result: the code returned no values. Length stop: the reply filled its context or output cap. Tools refused by Ollama: the model as served has no tool support. Other tool or call failure: a tool call written as text, another call error or a step that produced no cell and no error. Other: a harness error, no code or a failure of none of these kinds. Rows: Gemini, then open-weight, each ordered high to low by free-form pass rate, ties by pass rate over all 11 strategies. Gemini low: gemini-2.5-pro with a thinking budget of 128 tokens per call, gemini-3-flash at the minimal level.
