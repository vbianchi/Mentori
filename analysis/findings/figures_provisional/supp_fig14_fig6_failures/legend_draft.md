**Supplementary Figure 14 | How code-generation attempts failed, per model variant.** Attempts as in Figure 7: one model variant, one prompting strategy and one of 20 operations, run once (165 attempts run again after a rule change, the later run counted; n = 2,420 attempts). Failed attempts of each model variant under each prompting family, as a share of its n attempts, one per strategy and operation (n = 60 free-form, 80 introspection and 80 structured). Wrong values and no result as in Figure 7c. Length stops are shown apart from tool or call failure, other, which is split into tools refused by Ollama (the model as served has no tool support), other tool or call failure (a tool call written as text, another call error or a step that produced no cell and no error) and other (a harness error, no code or a failure of none of these kinds). Rows: Gemini, then open-weight, each by free-form pass rate, high to low, ties by pass rate over all 11 strategies. Gemini low: gemini-2.5-pro with a thinking budget of 128 tokens per call, gemini-3-flash at the minimal level.
